≥ 2 атак автоматически подтверждают DIT (клинически).

DIT больше не обязателен для диагноза РС в 2024 г., но используется для повышения специфичности в отдельных ситуациях.

Отметьте регионы, в которых выявлены типичные для РС очаги (симптомные или асимптомные). DIS выполнен при ≥ 2 из 5 регионов; ≥ 4 регионов достаточно для диагноза без доп. критериев.

Достаточно любого из методов при отсутствии лучшего объяснения (Panel 3, 2024).

Для ППРС ≥ 2 спинальных очага сами по себе fulfilment DIS (Panel 4).

Введите 0, если подсчёт не проводился.

Select 6 положителен, если:
• ≥ 6 очагов CVS+ при общем числе очагов ≥ 10, ИЛИ
• CVS+ очаги составляют большинство при общем числе очагов < 10.

Положительным считается наличие хотя бы одного из признаков (OCB и kFLC-индекс взаимозаменяемы).

Для диагноза РС необходимо отсутствие лучшего объяснения («no better explanation»).
